DO SEU JEITO

Escolha onde instalar

PC

Windows

No Edge ou Chrome, use o botão Instalar Órbita. Se ele não abrir a confirmação, procure a opção de instalar aplicativo no menu do navegador.

No Edge: ⋯ → Mais ferramentas → Aplicativos → Instalar este site como aplicativo. O nome pode variar entre versões.

↗

Brave e outros navegadores

Procure o ícone de instalação na barra de endereço ou a opção de instalar aplicativo no menu. Se seu navegador não oferecer instalação, continue usando o site ou abra este endereço no Edge ou Chrome.

MOBILE

Android e iPhone

No Android, use Instalar aplicativo ou Adicionar à tela inicial no navegador. No iPhone, abra no Safari e escolha Compartilhar → Adicionar à Tela de Início.

Prefere um atalho para Windows?

Baixe o ZIP, extraia e abra Órbita.url. Esse atalho abre o site no navegador padrão. Para ter uma janela independente, use a instalação acima.
