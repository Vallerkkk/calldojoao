PC

Instale e abra

Para atualizar, encerre a Órbita pela bandeja do Windows. Baixe o novo instalador, escolha a pasta e conclua a instalação. Abra Órbita pelo menu Iniciar ou pelo atalho da área de trabalho e entre na sua conta.

Quem usa a versão 1.0.0 ou 1.0.1 precisa instalar esta versão uma vez para ativar o atualizador. Seus dados são preservados.

◉

Continue por perto

Ao fechar a janela, escolha continuar na bandeja do Windows ou encerrar o aplicativo. Na bandeja, suas chamadas podem continuar. As próximas versões são baixadas em segundo plano e instaladas ao encerrar o aplicativo pela bandeja, sem reiniciar no meio de uma chamada.

Compartilhe uma tela ou janela e escolha se quer incluir o áudio do computador. Câmera e microfone só são ativados com permissão.

MOBILE

Android e iPhone

No Android, use Instalar aplicativo ou Adicionar à tela inicial no navegador. No iPhone, abra no Safari e escolha Compartilhar → Adicionar à Tela de Início.

Prefere usar sem instalar?

Baixe o ZIP completo, extraia tudo para uma pasta e abra Orbita.exe. Mantenha as DLLs e a pasta resources junto do executável.

Baixar versão ZIP ↓Windows 64 bits · aproximadamente 147 MB

Também pelo navegador

Se preferir, instale a versão web pelo Edge ou Chrome. No iPhone, use Safari → Compartilhar → Adicionar à Tela de Início.

A instalação da versão web é confirmada pelo navegador.

Notas da versão e verificação dos arquivos ↗

O instalador desktop desta versão não possui assinatura digital comercial e pode receber um aviso do Windows/SmartScreen. Não é possível garantir ausência de alertas. A Órbita não pede para desativar o antivírus ou as proteções do computador. O aplicativo não inicia automaticamente com o Windows. A versão web continua disponível.
